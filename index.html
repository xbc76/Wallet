Instalar Wallet Klub

En Chrome: abre el menú ⋮ y pulsa «Instalar aplicación» o «Añadir a la pantalla de inicio».

Si Chrome no ofrece «Instalar aplicación», es porque la página está abierta desde un archivo del dispositivo: en ese caso solo puede crear el acceso directo. Para instalarla como aplicación completa hay que abrirla desde una dirección https.

La aplicación instalada guarda sus datos aparte. Si ya tenías tarjetas, usa Ajustes → Copia de seguridad para exportarlas e importarlas.
